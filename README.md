**Portainer 社区版** 是一个轻量级的容器化应用服务交付平台，可用于管理 Docker、Swarm、Kubernetes 和 ACI 环境。它的设计目标是与使用一样简单易部署。该应用允许您通过"智能"GUI 和/或丰富的 API 来管理所有编排器资源（容器、镜像、卷、网络等）。

Portainer 由单个容器组成，可在任何集群上运行。它可以部署为 Linux 容器或 Windows 原生容器。

**Portainer 商业版** 基于开源版本构建，包含一系列专为企业用户需求设计的高级功能和特性（如 RBAC 和支持）。

## 隐私

**为了确保我们将开发工作集中在正确的地方，我们需要了解哪些功能最常被使用。为此，我们使用 [Matomo Analytics](https://matomo.org/)，该服务托管在德国，完全符合 GDPR 要求。**

当 Portainer 首次启动时，您可以选择**禁用**分析功能。如果您**没有**选择禁用它，我们将根据[我们的隐私政策](https://www.portainer.io/legal/privacy-policy)收集匿名使用数据。**请注意**，我们不会在任何时候发送或存储任何个人身份信息，我们仅使用这些数据来帮助改进 Portainer。

## 限制

Portainer 仅支持"当前版本 - 2 个 Docker 版本"。之前的版本可能可以运行，但不受支持。
